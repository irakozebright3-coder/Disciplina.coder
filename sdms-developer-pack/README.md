# SDMS developer pack

This repository branch contains a starter guide for the Express + Supabase migration architecture.

The companion UI enhancement pack previously prepared for the project includes framework-agnostic CSS and JavaScript for:
- Liquid hover buttons
- A circular ring-and-dot cursor (disabled for touch and reduced-motion preferences)
- An optional lightweight Canvas ambient background
- Integration examples

These are integration assets, not a complete rewrite of the original application. The original ZIP supplied for review contained numerous zero-byte source files, so a safe direct integration and successful production build cannot yet be confirmed. Obtain a complete source export before merging this branch or deploying.

Deployment target: Vercel (frontend), Render (Express API), Supabase (Auth and PostgreSQL).
